**Coffee Crush Using Python**

Coffee Crush project is implemented for managing bills, products, databases, etc in the Coffee shop.

This Project is implemented using Python, and tkinter.
We have successfully implemented a website for a coffee shop to automate manual daily activities. The website provides efficient billing, management, and real-time order tracking, allowing owners to seamlessly monitor daily collections and orders, ensuring efficiency and accuracy.

As the frontend developer, I was responsible for creating the user interface using Tkinter and integrating it with the backend billing module via a RESTful API. The integration enables real-time order updates and inventory tracking. By automating these processes, we have significantly reduced processing time and errors, leading to improved efficiency and customer satisfaction. 

**Recommended:**
*1) Python 3.0 version or above.
2) Install Tkinter Module
3) Install MySQL*

**Steps to Run the Projects:**
1) Open Database/SHOPDB.py file, check your MySQL username and password, and run the file.
2) Now run CoffeeCrush.py file.
3) Now Login with *Username:- Admin and Password:- Admin123*
4) Now Order Something.
